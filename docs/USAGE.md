# 사용 가이드

## 화면 구성

```
┌─ 사용자 산책 영역(roam_box) ─┐
│                              │
│        ( ˙ㅅ˙ )             │  ← 펫 (투명 배경 위의 텍스트)
│                ( ˙ㅅ˙ )      │
│                              │
└──────────────────────────────┘
```

기본 산책 영역은 모니터 우상단 220×140 박스. 우클릭 메뉴에서 변경 가능.

---

## 상태와 전환

```
                   90초 입력 없음
   ┌──────────┐  ────────────────►  ┌──────────┐
   │  awake   │                      │  asleep  │
   │ 두리번/  │  ◄──────────────── │   zzZ    │
   │ 점프/…   │   키/마우스 입력     └──────────┘
   └──────────┘                            │
        ▲                                  │ PC 잠금/절전 → 깸
        │                                  │ (강제로 asleep + 자는 모습으로 시작)
        └──────────────────────────────────┘
```

- **awake**: 기본 상태. 두리번거리고, idle 액션(점프/하트/춤 등)을 무작위로 함.
- **asleep**: 졸린 상태. `( ˘ㅅ˘ )zzZ` 만 반복.
- 전환: 키/마우스 입력 → awake, 90초 입력 없음 → asleep, PC 잠금에서 복귀 → 강제로 asleep.

## 우클릭 메뉴

### 산책영역 설정
펫이 자동으로 돌아다닐 직사각형 영역을 지정.

- **↖ 좌상단으로**: 펫을 원하는 위치로 드래그한 뒤 클릭 → 그 점이 박스의 좌상단
- **↘ 우하단으로**: 마찬가지로 우하단
- **리셋**: 기본 위치(우상단)로 복원

### 글씨 색깔
- 프리셋 7색: 검정 / 짙은회색(기본) / 흰색 / 핑크 / 민트 / 하늘색 / 머스타드
- **색깔 직접 고르기...**: Windows 표준 컬러피커
- ⚠️ `magenta(#ff00ff)` 와 비슷한 색을 고르면 투명 처리 색과 겹쳐 일부 글자가 비칠 수 있음

### 움직임 속도
| 옵션 | 배수 |
|---|---|
| 아주 느림 | ×2.0 |
| 느림 | ×1.5 |
| **보통 (기본)** | ×1.0 |
| 빠름 | ×0.65 |
| 아주 빠름 | ×0.4 |

배수가 낮을수록 빠름. 프레임 표시 시간, idle 간격 모두에 적용.

### 깨우기/재우기
- **지금 깨우기**: 강제로 awake (잠자기 시퀀스 무시)
- **지금 재우기**: 강제로 asleep (졸다가 잠 시퀀스 재생)

### 설정 초기화
색·속도·산책영역 모두 기본값으로. 설정 파일도 새로 씀.

### 종료
펫 종료. 현재 설정/위치가 마지막으로 저장됨.

## 상호작용 상세

### 마우스
| 동작 | 결과 |
|---|---|
| 펫 좌클릭 | 인사 → 스마일 → 하트 → 윙크 → 양손인사 → 부끄럼 → 음악 → 박수 → 춤 → 전화 (사이클) |
| 펫 5초 안에 6번+ 빠르게 클릭 | 짜증 — 화남 → 풀림 |
| 펫 5초 안에 10번+ 빠르게 클릭 | 이스터에그 — 테이블 뒤집기 → 다시 놓기 |
| 펫 드래그 | 위치 이동. 손 떼면 새 위치 자동 저장 |
| 펫을 좌우로 흔들기 (드래그 중 방향전환 3회+) | 어지러움 |
| 펫 우클릭 | 메뉴 |
| 화면 다른 곳 클릭 (잠든 중) | 펫 깜짝 놀람 |

드래그와 클릭 구분: 4픽셀 이상 움직이면 드래그로 인식.

### 키보드
| 동작 | 결과 |
|---|---|
| 아무 키 (잠든 중) | 일어나기 |
| 아무 키 (깨어있을 때) | last_input_time 갱신 (sleep 카운트다운 리셋) |
| 입력 없이 90초 | 졸다가 잠 |

## 애니메이션 종류 (총 39개)

### 평상시 (idle 중 무작위)
- `looking_around` - 두리번거리기
- `head_tilt` - 고개 갸웃
- `jump`, `bounce` - 점프 / 콩콩
- `shrug` - 어깨 으쓱
- `wink` - 윙크
- `thinking` - 생각하기
- `peek_a_boo` - 까꿍
- `shiver` - 추워서 떨기
- `hot_pant` - 더워서 헥헥
- `look_back` - 뒤돌아보기
- `snack` - 간식 먹기
- `selfie` - 셀카
- `run_right`, `run_left` - 좌/우로 달리기 (산책 시 자동 사용)

### 기쁨 / 인사 (펫 클릭 시 사이클)
- `wave`, `wave_both` - 한손/양손 흔들기
- `hearts` - 하트 뿅뿅
- `smile_grow` - 웃음 커지기
- `shy` - 부끄러워하기
- `dance` - 춤
- `music` - 음악 듣고 신나기
- `clap` - 박수
- `phone` - 전화 받기

### 감정 (희귀 idle / 자동 체인)
- `crying` → `stop_crying` - 울었다가 그치기
- `fall_down` → `get_up` - 넘어졌다가 일어나기
- `run_and_hug` → `hug` - 달려와서 안기

### 짜증 (연타 트리거)
- `angry` → `sulking_relief` - 화났다가 풀림 (펫 6번+ 빠른 클릭)
- `table_flip` → `table_unflip` - 책상 뒤집고 다시 놓기 (펫 10번+ 빠른 클릭)

### 잠
- `falling_asleep` - 졸다가 잠
- `sleeping` - 자는 중 반복
- `waking_up` - 일어나기

### 깜짝 / 어지러움
- `startled` - 깜짝 놀라기 (잠든 중 외부 클릭)
- `dizzy` - 어지러움 (드래그로 흔들었을 때)

각 애니메이션은 4프레임 정도의 시퀀스. idle 중에는 가중치 무작위로 재생 (두리번/고개갸웃 자주, 특수 액션은 가끔). `→` 표시된 페어는 첫 액션이 트리거되면 두 번째가 자동으로 뒤따라 재생됨.

## 설정 파일

위치: `~/.tinypet.json`  
Windows: `C:\Users\<username>\.tinypet.json`

### 포맷

```json
{
  "fg_color": "#222222",
  "speed": 1.0,
  "speed_key": "normal",
  "roam_box": [1680, 40, 1880, 180],
  "last_position": [1750, 100]
}
```

| 키 | 의미 | 예시 |
|---|---|---|
| `fg_color` | 글씨 색 (헥스 코드) | `"#ff6f91"` |
| `speed` | 시간 배수 (0.2 ~ 5.0) | `0.65` |
| `speed_key` | 라디오 버튼 표시용 | `"fast"` |
| `roam_box` | 산책 영역 `[x1, y1, x2, y2]` | `[1680, 40, 1880, 180]` |
| `last_position` | 마지막 위치 `[x, y]` | `[1750, 100]` |

### 저장 시점
- 색 변경 (프리셋 / 컬러피커)
- 속도 변경
- 산책영역 ↖/↘ / 리셋
- 펫 드래그로 위치 이동 (드래그 끝나는 순간)
- 정상 종료 (우클릭 → 종료)

**자동 이동으로 바뀐 위치는 저장 안 함** — 사용자가 직접 드래그한 위치만 기억.

### 손으로 편집
펫이 꺼진 상태에서 JSON을 직접 수정해도 됩니다. 잘못된 값이면 조용히 무시하고 기본값 사용.

### 초기화
- 우클릭 → 설정 초기화
- 또는 파일 삭제: `del %USERPROFILE%\.tinypet.json` (Windows)

## 자동 시작 등록

### Windows — 시작 폴더 (간단)
1. `Win+R` → `shell:startup` → Enter
2. `TinyPet.exe` (또는 `run.bat`) 의 **바로가기**를 그 폴더에 복사

### Windows — 작업 스케줄러 (안정적)
1. 작업 스케줄러 열기 → "기본 작업 만들기"
2. 트리거: "로그온할 때"
3. 동작: 프로그램 시작 → `TinyPet.exe` 경로 (또는 `pythonw -m tinypet`)
4. "가장 높은 권한" 체크는 보통 불필요
